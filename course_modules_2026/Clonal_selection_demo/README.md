## Running the Clonal Selection Demo in Google Colab

### What is Google Colab?

Google Colab (short for Colaboratory) is a free cloud-based platform that allows you to run Jupyter notebooks directly in your browser.  

It provides:
- A Python environment
- Access to CPUs and limited GPUs
- No local installation required
- Easy integration with GitHub

This means you can run the demo without installing software on your own machine.

## Step-by-Step Instructions

1. Click the link above.
2. Sign in with a Google account if prompted.
3. The notebook will open in Google Colab.
4. Click **Runtime** in the top menu.
5. Select **Run all** to execute all cells  
   OR  
   Run cells individually using the ▶ button.

## Important Notes

- If dependencies are missing, run any installation cells at the top of the notebook first.
- If you see a disconnected session, click **Reconnect** in the top right.
- Your session runs in the cloud, so any files created will not be saved permanently unless you download them.
